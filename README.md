==What does this project do?==
It serves as a diary where you can write diary entries, check, edit, delete, search (by date or specific word),
get stats (on number of words written, frequency of emotions, etc), making it 10 different options of usage! 

This is the complete menu (of usage):
1. Write a diary entry
2. See diary entries
3. Customize
4. Search by WORD
5. Search by DATE
6. Edit entry
7. Delete entry
8. See stats
9. Exit
10. Delete EVERYTHING

==How to use it?==
The program offers you options to choose in every window. You just need to type in the option and press the enter key to make it work!
